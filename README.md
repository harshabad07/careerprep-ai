# CareerPrep AI — Placement & Interview Assistant 🎓

**CareerPrep AI** is an interactive web assistant designed to help college students and fresh graduates prepare for campus placements, technical interviews, HR evaluations, DSA problem solving, aptitude tests, and resume optimization.

## 🚀 Features

- **Mock Interviews**: Conduct structured Technical and HR mock interviews with step-by-step evaluation and sample answers.
- **DSA Practice Bank**: Master arrays, hash tables, and core algorithms with time and space complexity explanations.
- **Aptitude Quizzer**: Practice quantitative and logical reasoning questions with step-by-step solutions.
- **Resume Checklist**: Professional guidelines and action-verb bullet point templates.
- **HR Preparation**: Standard behavioral question strategies using the STAR and PRESENT-PAST-FUTURE frameworks.
- **Local Persistence**: Save your chat history directly in your browser.

## 🛠️ Getting Started

To launch the CareerPrep AI chatbot locally:

```bash
python python.py
```

This will start a local HTTP server at `http://localhost:8000` and automatically open the application in your browser.
